# Data sources

The public code repository does not redistribute third-party raw datasets.
Obtain the original files from their creators and place them as follows:

```text
data/
├── batadal/
│   ├── BATADAL_dataset03.csv
│   └── BATADAL_dataset04.csv
├── gas/
│   └── IanArffDataset.arff
└── hai/
    ├── train1.csv
    └── test1.csv
```

## BATADAL

R. Taormina et al., “The Battle of the Attack Detection Algorithms: Disclosing
Cyber Attacks on Water Distribution Networks,” *Journal of Water Resources
Planning and Management*, 144(8), 04018048, 2018.
DOI: https://doi.org/10.1061/(ASCE)WR.1943-5452.0000969

## Gas Pipeline

T. Morris and W. Gao, “Industrial Control System Network Traffic Data Sets to
Facilitate Intrusion Detection System Research,” in *Critical Infrastructure
Protection VIII*, Springer, 2014, pp. 65–78. The required file is
`IanArffDataset.arff`.

## HAI 22.04

H.-K. Shin et al., “HAI Security Datasets,” official repository:
https://github.com/icsdataset/hai

Users are responsible for complying with each source's terms and license.
